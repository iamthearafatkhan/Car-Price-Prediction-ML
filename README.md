# Car Price Prediction ML 🚗💰

A machine learning-based web application built with **Python**, **Flask**, and **HTML/CSS** that estimates the resale market value of used cars based on key features like year, mileage, fuel type, transmission, and brand.

---

## 🔍 Project Overview

Accurately predicting used car prices requires analyzing various historical vehicle data points. This project implements a machine learning model integrated with a Flask backend to deliver instant, real-time car price estimates through a clean user interface.

### **Key Highlights:**
* **Machine Learning Pipeline:** Trained on automotive dataset attributes to predict vehicle valuations accurately.
* **Flask Web Server:** Provides a seamless interface connecting the ML model inference engine to the web frontend.
* **Interactive UI:** Simple HTML/CSS input form allowing users to select vehicle specs and receive price outputs immediately.

---

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Web Framework:** Flask
* **Frontend:** HTML5, CSS3
* **Data Processing & ML:** scikit-learn, Pandas, NumPy
* **Model Serialization:** Pickle / Joblib

---

## ⚙️ Features

* 🚘 **Multi-Attribute Input:** Accept features like manufacturing year, total kilometers driven, fuel type, transmission type, and brand.
* ⚡ **Instant Valuation:** Provides fast market price predictions upon form submission.
* 🧹 **Data Preprocessing:** Encodes categorical parameters and scales numeric inputs for reliable model evaluation.
